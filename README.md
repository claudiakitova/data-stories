# Data Stories

These are study projects, meant for learning and teaching data science.

| Project | About | Tools |
|---|---|---|
| [neural_networks](neural_networks/) | Sentiment analysis of IMDB movie reviews with a neural network, plus a function that scores the sentiment of any text | TensorFlow / Keras |
| [neighbourhoods_battle](neighbourhoods_battle/) | Clustered the neighborhoods of Krasnodar, Russia, by the venues around them to see which are the most comfortable to live in | pandas, geopy, scikit-learn (k-means) |
| [flights_prediction](flights_prediction/) | Predicted whether a flight arrives on time from its date, time, and route | pandas, scikit-learn (random forest) |
| [climate_change](climate_change/) | Global temperature trend from 1882 to 2014, fitted with linear regression three ways | NumPy, scikit-learn, seaborn |
| [music](music/) | Two music studies on datasets I built: listening habits in Moscow vs. St. Petersburg, and an analysis of ~500 top Caucasian songs from Yandex.Music using Spotify audio features | pandas, scikit-learn (PCA, t-SNE), plotly |

## Running

Each folder is self-contained: open the notebook in Jupyter or Google Colab. The data files it needs are next to it.
